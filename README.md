# PTA After Dark — quote cards

Public image hosting for @pta.afterdark posts (Instagram + Facebook).
Only approved cards go here.

- `cards/bN-M.jpg` — batch N, post M (matches the PTA After Dark Archive tracker)
- `cards/follow.jpg` — slide 2 on every post
- `cards/logo.png` — page logo

Direct image link format:
`https://raw.githubusercontent.com/alyvicreatives/pta-afterdark-cards/main/cards/<file>`
